# 모아랑

> 내 경험을 프로필로, 프로필을 함께할 팀으로.

한양대학교 ERICA 학생들이 자신의 경험을 소개하고, 팀플·대회에 함께할 팀원을 찾는 교내 커뮤니티 웹 서비스입니다. AI 프로필과 디지털 명함을 통해 자신을 소개하고, 모집·지원·대화를 거쳐 팀으로 연결되는 경험을 목표로 합니다.

- [노션 서비스 기획](https://app.notion.com/p/40a9acc1fa1580539a2ec9f640f615d1)
- 현재 단계: **목데이터를 사용하는 프론트엔드 프로토타입**
- 대상 학교: **한양대학교 ERICA**

## 1. 서비스 대상과 이용 흐름

학교 인증을 완료한 재학생·휴학생·졸업생을 대상으로 합니다. 교수·연구실 구성원은 별도 인증 후 연구실 정보를 관리하는 구조를 계획하고 있습니다.

```text
회원가입·학교 인증 → 경험 입력 → AI 프로필 생성·확인
→ 팀플·대회 탐색 → 지원 → 대화·수락 → 모집 종료 → 팀 페이지
```

학교 인증, 실제 AI 생성, 서버를 통한 지원·대화는 앞으로 연결할 기능입니다.

## 2. 로컬 실행

별도 패키지 설치나 빌드 없이 실행할 수 있습니다. Python 3가 설치된 환경에서 다음 명령을 실행합니다.

```sh
cd moarang
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 **http://127.0.0.1:4173/** 에 접속합니다. 이미 `moarang` 폴더 안이라면 첫 번째 명령은 생략합니다. 서버 종료는 실행한 터미널에서 `Ctrl+C`를 누릅니다.

`index.html`을 직접 열 수도 있지만, 브라우저 저장소와 클립보드 동작을 확인할 때는 위 실행 방식을 권장합니다.

### 처음 확인할 때

1. 로그인 화면에서 **입력 없이 로그인** 버튼을 누르면 홈으로 이동합니다.
2. 회원가입은 이름·학과를 프로필에 반영하는 화면 흐름입니다. 실제 계정은 생성되지 않습니다.
3. 기본 프로필은 **남궁길 / 인공지능학과**입니다. 소개와 경력은 프로젝트 시연용 임시 정보입니다.
4. 비밀번호는 저장·전송하지 않습니다. 테스트할 때 실제 비밀번호를 입력하지 마세요.

## 3. 화면 구성

데스크톱에서도 약 420px 너비의 스마트폰 형태로 표시합니다. 모바일에서는 화면 너비에 맞춰 표시하며, 아이폰 형태의 상태 표시줄과 다이내믹 아일랜드를 사용합니다. 상태 표시줄의 시간·배터리는 고정된 시각 요소입니다.

| 메뉴 | 구성 |
| --- | --- |
| 홈 | 프로필 안내, 팀플 게시판·대회 게시판의 최근 제목 각각 5개, 캠퍼스 소식 |
| 팀 찾기 | 팀플·대회 통합 최신순 목록, 검색, 단과대·학년 필터, 관심 모집 |
| 연구실 | 단과대별 연구실 탐색, 교수·학과·연구 분야 검색, 상세 소개와 외부 링크 |
| 커뮤니티 | 학교생활·인턴·활동 및 홍보 글 탐색과 작성 |
| 내 정보 | 프로필·경험, 명함, 지원 현황, 팀, 친구, 공개 범위, 학교 인증 안내 |

홈에서 게시판의 ‘전체 보기’를 누르면 해당 유형의 카드형 목록으로 이동합니다. 모집 목록은 유형보다 **게시 날짜·시간 최신순**을 우선합니다. 새 글은 실제 작성 시각을 저장하며, 날짜 표시는 한국 시간 기준입니다.

단과대 선택에는 공학대학, 소프트웨어융합대학, 약학대학, 첨단융합대학, 글로벌문화통상대학, 커뮤니케이션&컬처대학, 경상대학, 디자인대학, 예체능대학과 LIONS칼리지를 제공합니다. 학년은 1~4학년을 선택할 수 있습니다.

## 4. 현재 구현된 흐름

| 영역 | 프론트엔드에서 확인할 수 있는 동작 |
| --- | --- |
| 로그인·회원가입 | 로그인 → 홈, 가입 → 로그인, 비밀번호 표시·확인, 로그아웃 |
| 프로필 | 이름·학과·소개·역량·경험 편집, 입력 내용 기반 프로필 초안 확인 |
| 디지털 명함 | 명함 미리보기, 소개 텍스트 복사 |
| 모집 탐색 | 검색, 유형·단과대·학년 필터, 최신순 정렬, 저장·해제 |
| 지원 | 역할·지원 동기 작성, 지원 현황 확인, 지원 취소 |
| 모집 관리 | 모집 글 작성, 목 지원자 수락·거절, 모집 종료 후 수락된 멤버로 팀 생성 |
| 대화 | 친구·모집자·팀 대화 화면, 브라우저에 메시지 저장 |
| 연구실 | 목록·상세·검색·필터, 실제 연구실 홈페이지 및 연락처 연결 |
| 커뮤니티 | 검색·분류·상세 보기·글 작성 |
| 기타 | 공개 범위 선택 저장, 친구 삭제, 알림, 신고 화면 |

연구실에는 이겨레 교수 연구실과 조영은 교수의 **AI Systems Lab(AISL)** 및 가상 연구실이 포함되어 있습니다. 이겨레 교수의 소속은 팀 요청에 따라 인공지능학과로 반영했습니다.

- [이겨레 교수 Google Scholar](https://scholar.google.com/citations?user=xnai7YcAAAAJ&hl=ko)
- [AISL 홈페이지](https://hyuaisl.github.io/)

모집 글·지원자·교수·연구실·대회 정보에는 시연용 데이터가 포함됩니다. 대회 게시글은 실제 행사 일정이나 참가 자격을 보증하는 정보가 아닙니다.

## 5. 노션 기획상 규칙과 연결 예정 기능

### AI 프로필·명함

기본 정보, 프로젝트·대외활동·수상 경력과 포트폴리오 링크를 입력하면 AI가 사실을 정리해 초안을 생성합니다. 사용자가 확인·수정한 뒤 공개합니다. QR·링크 명함은 동일한 프로필에 연결되고 공개 범위를 따릅니다.

현재 AI 호출, QR 발급, 외부에서 접근 가능한 프로필 링크는 연결하지 않았습니다.

### 프로필 공개 범위

공개 대상은 ‘전체 / 친구 / 지원한 게시물 작성자 / 팀원’이며 복수 선택합니다.

- ‘전체’는 학교 인증 이용자 모두를 포함합니다.
- 아무 대상도 선택하지 않으면 본인만 열람합니다.
- 지원 취소 또는 모집 종료 시 해당 지원으로 부여된 열람 권한을 해제합니다.
- 친구·팀원 등 다른 공개 조건을 충족하면 해당 조건의 권한은 유지합니다.
- 같은 팀에 속한 이용자에게만 팀원 권한을 적용합니다.

현재는 선택값만 브라우저에 저장합니다. 실제 프로필 열람 허용·차단은 서버에서 구현해야 합니다.

### 모집과 팀 결성

모집 글에는 목표, 활동 기간, 모집 인원, 필요한 역할·역량, 활동 방식과 주당 예상 시간을 표시합니다. 지원자는 프로필·지원 동기·가능한 역할을 제출하고, 팀장은 검토·대화 후 수락 또는 거절합니다. 모집 종료 시 팀장과 수락된 지원자가 팀 멤버로 등록됩니다.

현재 지원자는 목데이터이며, 사용자 간 실시간 동기화와 실제 알림은 제공하지 않습니다.

### 연구실·운영

연구실 상세에는 교수·연구실 소개, 연구 분야, 홈페이지, 이메일, 모집 정보를 제공합니다. 향후 인증된 교수·구성원이 직접 등록·수정하는 기능이 필요합니다. 학교 인증, 연구실 관리자 인증, 신고·차단 처리, 스팸·중복 글 관리도 서버 연결 대상입니다.

## 6. 코드 구성

```text
moarang/
├── index.html               # 앱 골격, 상태 표시줄, 화면·메뉴·알림 영역
├── style.css                # 모바일 앱 레이아웃, 컴포넌트와 반응형 스타일
├── app.js                   # 목데이터, 화면 전환, 폼과 상태 변경
├── assets/
│   └── hanyang-erica.png     # 공식 ERICA 사이트에서 가져온 학교 로고
└── README.md
```

HTML·CSS·JavaScript로 구성되어 있으며, 프레임워크와 서버 API 의존성은 없습니다. 한글 웹 폰트는 Google Fonts를 사용하고, 연결되지 않으면 시스템 글꼴로 표시합니다.

### 주요 수정 위치

- `COLLEGES`, `YEARS`: 단과대·학년 공통 선택지
- `seed`: 기본 프로필·게시글·친구·커뮤니티 데이터
- `morePosts`, `revisedPosts`, `sampleTimes`: 추가 모집 데이터·수정 내용·초기 게시 시각
- `home()`, `team()`, `lab()`, `community()`, `profile()`: 하단 메뉴별 화면
- `renderAuth()`: 로그인·회원가입 화면
- `labs`: 연구실 데이터
- `publish()`, `submitApply()`, `endRecruit()`: 모집 등록·지원·팀 생성 흐름

현재 데이터 보정 코드가 앱 시작 시 실행되므로 `revisedPosts`에 지정된 기본 모집 글의 변경 사항은 새로고침 때 다시 적용됩니다. 기본 글을 수정할 때는 해당 데이터도 함께 수정하세요.

## 7. 데이터 저장과 초기화

데이터는 각 브라우저의 `localStorage` 키 **`moarang-v1`**에 저장합니다. 다른 기기·브라우저·접속 주소와 공유되지 않으며, 서버로 전송하지 않습니다. `localhost`와 `127.0.0.1`도 서로 다른 저장소를 사용합니다.

초기화하려면 개발자 도구의 Application → Local Storage에서 `moarang-v1` 키를 삭제하고 새로고침합니다. 초기화하면 직접 작성한 글, 지원 내역, 프로필 수정과 메시지가 사라집니다.

## 8. 팀 확인 체크리스트

- 로그인 버튼으로 홈에 진입할 수 있는지 확인합니다.
- 홈의 제목을 누르면 상세, 전체 보기를 누르면 해당 게시판으로 이동하는지 확인합니다.
- 팀 찾기에서 최신순·검색·단과대·학년 필터를 확인합니다.
- 지원 후 지원 현황에 표시되고, 취소하면 제거되는지 확인합니다.
- 모집 글 작성 → 지원자 수락 → 모집 종료 → 나의 팀 생성 흐름을 확인합니다.
- 프로필 수정 후 새로고침해도 변경 사항이 유지되는지 확인합니다.
- 연구실 필터, 상세 화면과 외부 링크를 확인합니다.
- 좁은 모바일 화면과 데스크톱에서 메뉴·폼·알림 위치를 확인합니다.
